# Kelechi Ukanwa: Portfolio

Personal portfolio website for Kelechi Ukanwa, Executive Assistant to founders, with a background in fraud and payment operations.

## Pages

- `index.html`: home page with services, a finance case study summary, content work and experience
- `case-study.html`: the full case study, linked from the "Read the full case study" button
- `assets/`: images and videos used on both pages

## Hosting

This is a plain static site with no build step. To deploy it on Vercel, import this repository and click Deploy, leaving every setting at its default. On Netlify, connect the repository with no build command and set the publish directory to the repository root.
